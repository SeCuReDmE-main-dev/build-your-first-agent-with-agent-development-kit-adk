# Repository instructions for coding agents

This is a public educational repository for the Google Skills course **Build Your First Agent with Agent Development Kit (ADK)**.

Before changing files, report the working directory, branch, HEAD, and working-tree state. Preserve learner edits and keep each change small enough to explain from the open `agent.py` file.

## Boundaries

- Never read, print, commit, transmit, or summarize the value of any `.env` variable.
- Keep `.env`, `.adk`, virtual environments, caches, and logs untracked.
- Bind development services to `127.0.0.1` unless the human explicitly authorizes another boundary.
- Do not add cloud deployment, billing, permissions, telemetry, or persistent infrastructure as an implicit next step.
- Separate observed results from course claims, hypotheses, and planned work.
- Do not treat this first agent as proof that memory, tools, CCP, context caching, or multi-agent orchestration has been implemented.

## Learning workflow

For each milestone, record: source, objective, smallest code change, command executed, observed result, limitation, and one next action. Prefer a direct example tied to SecuredMe Education only when the example does not introduce private project material.

The human entry point is `HUMAN.md`. Keep it current whenever the technical structure changes enough to alter how the learner should return to the project.
